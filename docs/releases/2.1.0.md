simpled 2.1.0 adds the simpled controller: one small service per Docker environment
that issues and renews the gateway's certificates on Swarm, reports every deployment's
health and version, and serves a private status API for `simpled status`, `logs` and
`wait`.

## Before you upgrade

- **Docker env specs need a `controller` block.** It names the gateway host the
  controller is served on, under `/simpled/`:

  ```yaml
  controller:
    host: web            # an alias from gateway.hosts
  ```

  A Docker env spec without it fails validation and says what to add. The host can
  keep serving your app; only a service routed at `/simpled` or below on it is
  refused. Kubernetes and `simpled local` are unchanged.
- **`/.well-known/simpled/version` is gone on Docker.** Use
  `/simpled/version/<deployment>` on the controller's host. Kubernetes keeps the old
  path.
- **The Swarm gateway stack is `simpled`, not `ingress`.** The first deploy with
  2.1.0 removes the old `ingress` stack itself (`step retire-legacy-stack`), which
  takes the gateway down for a few seconds once. The new images are pulled first, so
  a pull failure leaves the old gateway serving. On standalone Docker the gateway
  container is now `simpled-gateway`.
- **The controller runs the image `ghcr.io/vkubiv/simpled:2.1.0`.** Deploy targets
  need to reach ghcr.io, or set `SIMPLED_CONTROLLER_IMAGE` when running `deploy.sh`.

## Certificates on Docker Swarm

- With `tls.letsencrypt`, the controller is the ACME client instead of Traefik.
  Each domain's certificate is a Swarm secret, so every node has it, and a global
  gateway with Let's Encrypt now works.
- The first deploy starts with self-signed placeholders; the controller issues the
  real certificates, usually within a minute, one domain at a time, and renews them
  30 days before they expire.
- Certificates Traefik already issued are kept: `deploy.sh` imports
  `letsencrypt/acme.json` into secrets on the first deploy, and
  `simpled tls import <acme.json>` does the same by hand.
- On standalone Docker, Traefik still runs ACME itself.

## Health, versions and the private API

On the controller's host:

| Route | |
|---|---|
| `GET /simpled/health` | The whole environment: gateway, certificates, every deployment. |
| `GET /simpled/health/<deployment>` | One deployment: `status`, `converged`, `version`, and `tls` on Swarm. |
| `GET /simpled/version/<deployment>` | Application, version, deployed_at. |
| `/simpled/api/v1/...` | Services, tasks, logs, gateway and nodes, behind `controller.read_token`. |

Health routes answer 200 when healthy and 503 otherwise, so an uptime check needs no
JSON.

## New commands

- `simpled status`: every deployment and its services.
- `simpled logs <deployment> <service> [-f]`: a service's log, aggregated across
  Swarm nodes.
- `simpled wait <deployment> --version <v>`: waits until the deployment runs that
  version, converged and healthy, for CI.
- `simpled tls import <acme.json>`.
