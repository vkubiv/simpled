Releases now include a Linux arm64 binary, `simpled_linux_arm64.tar.gz`.

- Swarm targets with `target_platform: linux-arm64` no longer need
  `--target-binary`: `prepare-deployment` downloads the arm64 binary from the
  release, as it does the amd64 one.
- `simpled update` works on Linux arm64 machines.

Nothing else changes from 2.0.0.
