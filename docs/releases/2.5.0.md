simpled 2.5.0 prunes unused images on every node of a swarm, not only the one that
runs `deploy.sh`.

## Images pruned on every node

- **`./simpled step prune-images`** replaces the `docker image prune -af` in the Swarm
  `deploy.sh`. It runs a `global-job` service of the controller image
  (`SIMPLED_CONTROLLER_IMAGE` overrides it) with the Docker socket mounted. Its task on
  each node removes every image no container uses and prints what it reclaimed. The
  service is removed once every node is done, or after 5 minutes.
- **Still before the rollout**, so the release that is running stays on each node as
  the rollback image.
- **A failed job does not stop the deploy:** `deploy.sh` then prunes its own node, as
  before, and carries on.

## Upgrading

- Images of stopped task containers are never pruned, and Swarm keeps up to 5 tasks
  per slot by default. Set the swarm's task history limit once on a manager, e.g.
  `docker swarm update --task-history-limit 2`, so each node keeps the current release
  and the previous one.
