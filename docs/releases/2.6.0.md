simpled 2.6.0 lets an env spec keep each deployment in a file of its own, and warns
when a deployment sets an environment value the app spec ignores.

## A deployment in its own file

- **`file:`** in a deployment's entry reads the deployment from a file next to the env
  spec. The env spec keeps what the deployments share (`gateway`, `registry`,
  `controller`, `networks`), and the file holds what would be written under the
  deployment's name:

  ```yaml
  # envspec.yaml
  deployments:
    shop:  { file: shop.yaml }
    admin: { file: admin.yaml }
    tools:                      # written here, as before
      primary_host: admin
      application: { name: tools }
  ```

- **Only in the env spec's directory**, ending in `.yaml` or `.yml`, so every path in
  the file resolves as it would inline. `file` stands alone in its entry, and a key
  in the file that is not a deployment field is an error. A name YAML reads as a
  number or a boolean is quoted: `"2024": { file: y2024.yaml }`.
- **Nothing else changes:** the deployment keeps its name, refers to the env spec's
  hosts and networks, and may `extends` any other deployment, in a file or not.
  `localenv.yaml` takes the same form. Messages about volumes, the Swarm object size
  limit and ignored environment values name the file the deployment is written in.
  See [A deployment in its own file](../reference.md#a-deployment-in-its-own-file).

## Ignored environment values

- **Validation warns** when a deployment's `environment:` sets a variable the app spec
  computes (`relative` or `internal`), or one it does not declare at all; both were
  dropped without a word. Declare the variable `external` or `optional` to set it
  from the env spec. Undeclared names are not reported on `local` env specs, where
  testspec suites read the deployment environment directly.

## Control plane

- The sync reads deployments written in files of their own, and an envspec is
  unreadable while one of its files is. Abstract deployments are no longer listed as
  deployments: they are templates simpled never deploys, and their rows go away on
  the next sync.
